# 1. 주제와 요구사항

## 주제 고르는 기준

| 기준 | 왜 |
|---|---|
| 표 3~5개, 1:N 관계 하나 이상 | DB 수업의 ERD·정규화를 보여줄 수 있다 |
| 기능 3개로 나뉜다 | 한 사람이 기능 하나를 화면부터 DB 까지 맡는다 |
| 기능마다 CRUD 가 된다 | 평가 CRUD 40점 |
| 4주 안에 끝나는 크기 | 다 못 만들면 발표할 게 없다 |

| REQ-03 | | | | |
| REQ-04 | | | | |
