# 9. 더 쓸 데이터와 운영자 계정

2026-11-20. 지금 받아 둔 키로 더 할 수 있는 것, 새로 받으면 좋은 것, 그리고 사용자 화면에서 개발자 것을 걷어 내고 운영자만 들어오는 길을 어떻게 둘지 정리했다.
API 칸 이름·한도 중 공식 문서로 못 본 것은 "확인 필요"로 남겼다.

## 1. 지금 키로 바로 되는 것

| 데이터 | 키 | 붙일 곳 | 사용자에게 보이는 것 | 담당 |
|---|---|---|---|---|
| 한국천문연구원 특일 정보(`getRestDeInfo`) | 공공데이터포털(이 계정에 이미 승인돼 있다) | 방 만들기 날짜 칸 | 고른 날이 연휴면 "연휴라 길이 막힐 수 있어요". 출발일 후보로 다음 연휴 | 박재현 |
| 카카오 로컬 카테고리 검색(대형마트 `MT1`, 편의점 `CS2`) | 카카오 REST | 장보기 역할 근거, 숙소 카드 | "숙소에서 가장 가까운 마트 4.2km · 차 필요". 차 없는 사람에게 장보기를 덜 준다 | 문지훈 |
| 오피넷 시도별 평균(`avgSidoPrice.do`) | 오피넷 | 이동·회비 근거 | 전국 평균 대신 출발 시·도 기름값 | 문지훈 |

## 2. 새로 받으면 좋은 것

| 데이터 | 받을 곳 | 쓸모 | 주의 |
|---|---|---|---|
| 기상청 중기예보(3~10일) | 공공데이터포털 [15059468](https://www.data.go.kr/data/15059468/openapi.do) | 단기예보(3일)보다 앞서 출발 일주일 전 날씨 | 활용신청만 하면 같은 키 |
| 한국관광공사 고캠핑 정보 | 공공데이터포털 | 캠핑 여행이면 캠핑장 전기·온수·개수대 | 공공누리 1유형 |
| 카카오모빌리티 다중 경유지 길찾기 | 카카오모빌리티 | 운전자가 친구들을 태우러 가는 순서(픽업 경로)와 시간 | 별도 권한 신청이 필요할 수 있다. **상업적으로 쓰면 무료 쿼터 안이어도 제휴 계약이 필요하다**고 담당자가 답했다. 경로 결과를 저장해 다시 쓰지 말라는 답도 있어 저장하지 않는다 |
| 카카오톡 공유(JavaScript SDK) | 카카오 콘솔 JavaScript 키 + 도메인 등록 | 지금은 "카톡용 글 복사". 카드 모양 메시지(방 이름·역할·초대 버튼)로 바로 보낸다 | REST 로는 안 되고 JS SDK 가 필요하다. 스택에 스크립트가 하나 느니 팀이 먼저 정한다 |
| 에어코리아 대기오염 | 공공데이터포털 | 바베큐 날 미세먼지 | 우선순위 낮음 |

순서는 사용자가 바로 느끼는 것부터: 특일(연휴) → 마트 거리 → 신고 숙소 → 날씨 → 카톡 공유 카드 → 픽업 경로.

## 3. 사용자 화면에 개발자 것이 보이지 않게

사용자는 키 이름, 설정 파일, 개발용 기능을 몰라도 된다. 화면에는 사람 말만, 까닭은 서버 로그와 README 에 둔다.

| 있던 것 | 지금 |
|---|---|
| 로그인 화면 "카카오 키가 아직 없어 … (KAKAO_CLIENT_ID)" | "지금은 로그인을 쓸 수 없어요. 잠시 뒤 다시 와 주세요." |
| 역할 보드 "카카오 REST 키가 없어 … secrets.properties 에 …" | "지금은 길찾기를 쓸 수 없어 이동 근거를 셀 수 없어요." 까닭은 `log.warn` |
| 예시 방, H2 콘솔 | 개발용 로그인은 2026-11-20 에 지웠다. 예시 방은 시험(`TestTripData`)에만, H2 콘솔은 `H2_CONSOLE=true` 일 때만 |

새 화면을 만들 때도 같다: 오류 문구에 키·파일·클래스 이름을 넣지 않는다.

## 4. 운영자(개발자) 계정: 카카오 로그인 + 허용 목록

개발용 로그인은 지웠으니 시연·운영은 이것을 쓴다. 지금은 설계만 적어 두고, 박재현(로그인·보안 담당)이 만든다.

```
카카오 로그인 → KakaoUserService 가 loginId("kakao:회원번호")를 만든다
   → 회원번호가 ADMIN_KAKAO_IDS 에 있으면 ROLE_ADMIN 을 같이 준다
   → SecurityConfig: /admin/**, /api/admin/** 는 hasRole("ADMIN"), 나머지는 지금 그대로
```

| 정할 것 | 값 |
|---|---|
| 누가 운영자인가 | 환경변수 `ADMIN_KAKAO_IDS=1234567,7654321`(카카오 회원번호, 쉼표). 코드·저장소에 번호를 적지 않는다 |
| 내 회원번호 알기 | 한 번 카카오로 로그인하면 서버 로그의 loginId(`kakao:…`)에 나온다 |
| 운영자 화면 | 방 수·참여자 수, 바깥 API 상태(키 있음, 오늘 실패 수), 시연용 예시 방 열기(지웠던 개발용 로그인이 하던 일) |
| 개발용 로그인 | 지웠다(2026-11-20). 운영자 계정이 대신한다 |
| 일반 사용자 화면 | 운영자 메뉴·링크를 아예 그리지 않는다(숨김이 아니라 서버가 안 보냄) |

## 5. 디자인 바탕을 검증된 것으로

직접 만든 값 대신 널리 쓰이고 근거가 있는 것을 바탕으로 바꿨다.

| 무엇 | 쓰는 것 | 까닭 |
|---|---|---|
| 글꼴 | [Pretendard](https://github.com/orioncactus/pretendard) 1.3.9 가변, dynamic subset(cdnjs, 해시 고정) | 한국어 웹에서 가장 널리 쓰는 본문 글꼴, SIL OFL(상업 사용·수정 허용). 쓰는 글자만 받아 처음 받는 양이 작다. 못 받으면 시스템 글꼴 |
| 글자 크기 | 12·14·16·20·24·32 여섯 단계(`--fs-*`) | 본문 16 은 휴대폰에서 확대 없이 읽히는 기준. 크기를 여섯으로 묶어야 위계가 보인다 |
| 숫자 | `tabular-nums` | 금액·인원 숫자 폭이 같아 줄이 흔들리지 않는다 |
| 누름 크기 | 44px | Apple HIG 44pt, WCAG 2.2 권장 |
| 카카오 로그인 단추 | [카카오 로그인 디자인 가이드](https://developers.kakao.com/docs/latest/ko/kakaologin/design-guide): 바탕 #FEE500, 글자 검정 85%, 둥글기 12, 문구 "카카오 로그인" | "카카오로 시작하기"는 카카오싱크 전용 문구였다. **공식 말풍선 심볼이 아직 없다.** 콘솔 [도구 > 리소스 다운로드 > 카카오 로그인]에서 받은 파일을 넣어야 가이드를 다 지킨다 |
| 짧은 알림 | 토스트(`showToast`) | "복사했어요"처럼 결과만 알리는 말은 화면 아래에 잠깐. 막힘·오류는 위 안내 칸(`showNotice`) |
| 더 볼 것 | [KRDS 범정부 디자인 시스템](https://www.krds.go.kr) | 공개된 한국어 컴포넌트·접근성 기준. 다음에 입력·오류 문구를 맞출 때 본다 |

## 6. 운영 준비(2026-11-20)

개발용이 아니라 실제 사용자가 들어오는 서버를 기준으로 맞춘 것.

| 무엇 | 지금 | 까닭 |
|---|---|---|
| 오류 화면 | `templates/error/404.html`, `5xx.html`. 오류 번호·영어 없이 "찾는 화면이 없어요" + 처음 화면으로 | Spring 기본 화이트라벨 페이지는 개발자 화면이다 |
| 연결 끊김·서버 오류 | `common.js api()` 가 공통으로 "인터넷 연결이 끊긴 것 같아요", "잠시 문제가 생겼어요" | 화면마다 빠뜨리지 않게. 화면이 더 맞는 말을 쓰면 그 말이 덮는다 |
| 보안 머리(CSP) | 스크립트는 우리 서버와 jQuery CDN 만, 화면 안 `<script>` 는 모두 파일로 옮김. `frame-ancestors 'none'`, Referrer-Policy | 끼어든 스크립트가 돌지 않게(XSS 한 겹 더), 남의 사이트가 우리 화면을 틀에 넣지 못하게 |
| 정적 파일 | css·js 주소에 내용 해시(`style-b865….css`), 1년 캐시, gzip | 두 번째부터는 받지 않고, 고치면 주소가 바뀌어 새로 받는다. 휴대폰 데이터로 처음 받는 양도 준다 |
| 바닥글 | "© 2026 TripMate" | 팀 과제 표시는 README 에 |
| 배포 때 켤 것 | `COOKIE_SECURE=true`, `FORWARD_HEADERS=framework`, 카카오 Redirect URI 에 배포 주소 | 보안 점검 PR(#8)에서 칸을 만들어 두었다 |

카카오 로그인 단추는 콘솔에서 받은 공식 완성형 그림(`kakao_login_kr_large.svg`)으로 바꿨다.

남은 것: 카톡 미리보기 이미지(og:image, 1200×630 PNG), 실제 휴대폰·카톡 안 브라우저 확인.
