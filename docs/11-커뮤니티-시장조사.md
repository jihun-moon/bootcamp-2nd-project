# 11. 커뮤니티에서 본 단체 여행 불만과 TripMate 가 메울 곳

2026-11-20 조사. 실제 커뮤니티 글을 열어 읽고, 불만을 주제별로 묶어 TripMate 기능과 맞대었다.

## 1. 어디를 봤나

| 곳 | 본문까지 읽음 | 못 연 것 |
|---|---|---|
| 클리앙, 에펨코리아, 루리웹, 디시인사이드, 뽐뿌 | 17개 | 엠엘비파크(검색에 안 걸림), 루리웹 1개(404) |
| 네이트판, 인스티즈, 뉴스 기사(헤럴드, 인사이트, 경향) | 14개 | 블라인드(402), 더쿠(403), 당근 모임(403)은 검색 요약만 |
| 앱스토어(KR) 리뷰: 카카오페이, 토스, 트리플, 트랩플랜 | 보이는 리뷰만 | 구글플레이 리뷰 본문 |

한계도 적어 둔다. 찾은 글은 대부분 2~7명 여행이었고, 10명 넘는 MT·펜션 글은 드물었다. 장보기·설거지 다툼은 직접 사연을 거의 못 찾았다.

## 2. 가장 자주 나온 불만

두 갈래 조사(남초·여초 커뮤니티)에서 같은 것이 위로 올라왔다.

| 순위 | 불만 | 대표 글 |
|---|---|---|
| 1 | 운전한 사람 몫(기름값·톨비·수고비)에 기준이 없다. 매번 댓글이 갈린다 | 클리앙 "운전자에게 얼마나 보상", 에펨 "친구가 기름값을 속임", 블라인드 "자차면 기름값 n빵 어떻게" |
| 2 | 준비를 한 명이 다 떠안고 나머지는 "아무거나" 또는 불평 | 네이트판 "같이 여행할 때 비호감인 친구"(조회 약 18.8만), 루리웹 "가족여행 7명 준비 다 떠맡음" |
| 3 | 정산이 불투명하고 총무만 손해 | 인스티즈 "1/N 정산 요청한 사람이 제일 많이 냄", 디시 "동호회 회비 회계를 안 밝힘"(댓글 370) |
| 4 | 빠지는 사람 돈 처리 규칙이 없다 | 루리웹 "불참자에게 예약금 환불?"(2026-11-14), 루리웹 "취소했는데 돈 안 돌려주는 친구" |
| 5 | 쓴 몫이 다른데 1/N(술 안 마신 사람, 차 안 탄 사람) | 클리앙 "술 안 마셨는데 술값", 경향신문 2026-06-07 |
| 6 | 펜션 기준 인원 넘으면 추가요금. 69.9만 원 보고 갔다가 88.9만 원 | 헤럴드경제 2025-08-31(가평 7명), 인스티즈 "독채인데 전체 쓰려면 추가금" |

이미 쓰는 해결법은 따로 논다. 날짜는 카톡 투표, 돈은 모임통장, 계산은 엑셀이다. "누가 무엇을 맡고, 예외는 어떻게 나눌지"를 미리 정해 주는 도구는 못 찾았다.

## 3. TripMate 와 맞대기

| 불만 | 지금 TripMate | 이번에 바꾼 것 | 남은 것 |
|---|---|---|---|
| 1 운전자 몫 | 길찾기·기름값으로 1인 교통비 | "모두 나누면 9,600원 / 운전한 사람은 빼고 12,800원"을 나란히 보인다(`perPassenger`). 어느 쪽인지는 그룹이 고른다 | 운전자 수고비를 방 규칙으로 정해 두기 |
| 2 한 명이 떠안음 | 설문으로 역할 추천 | 마지막 사람이 설문을 끝내면 역할이 저절로 정해진다. 방장이 단추를 안 눌러도 된다 | 설문 안 한 사람에게 보낼 알림 글은 있음. 자동 알림은 카톡 메시지 API 가 필요해 보류 |
| 3 정산 불투명 | 결과를 카톡 글로 | 결과 글에 두 교통비 기준이 같이 들어간다 | 실제 송금은 토스·카카오페이에 맡긴다(맞붙지 않고 잇는다) |
| 4 빠지는 사람 | 없음 | | 방 규칙 카드: "전날 빠지면 예약금 환불 안 함" 같은 것을 방장이 고르고 모두가 본다 |
| 5 다른 몫 1/N | 없음 | | 방 규칙 카드에 "술값 따로" 칸 |
| 6 펜션 추가요금 | 숙소 링크 가격 | 링크를 붙이면 1박 가격과 1인 몫을 바로 센다 | 숙소 카드에 "기준 인원 확인" 칸. 링크 페이지가 기준 인원을 주면 읽는다 |

## 4. 다음에 지을 것(순서)

1. **방 규칙 카드.** 방장이 세 가지를 고른다. 운전자 기름값(같이 낸다 / 빼 준다), 전날 불참 예약금(돌려준다 / 안 돌려준다), 술값(같이 / 따로). 모두의 개요 화면 맨 위에 보이고 결과 카톡 글에도 들어간다. 커뮤니티 불만 1, 4, 5 가 모두 "미리 안 정했다"에서 시작해서 순위가 가장 높다
2. **숙소 기준 인원.** 링크에서 읽거나 올린 사람이 적고, 방 인원보다 적으면 카드에 "기준 n명, 추가요금 확인"을 붙인다
3. **날짜 정하기.** 근거가 약해(직접 다툼 글을 못 찾음) 뒤로 미룬다

## 5. 발표용 사례 카드

실제 사연 하나를 보여 주고, 왜 싸웠는지 짚고, TripMate 화면 하나로 답한다. 사연은 요약이고 원문 주소는 6절에 있다.

### 카드 1. "10시간 혼자 운전했는데 기름값만 n빵"
- **사연**: 셋이 담양 왕복. 차주가 10시간 넘게 혼자 운전했다. 댓글이 "기름값·톨비만 나누자", "몇만 원 빼 주면 오히려 서운하다"로 갈렸다(클리앙, 2022-06)
- **왜 싸웠나**: 출발 전에 "운전자도 내나"를 안 정했다. 끝나고 나서 숫자를 꺼내면 누가 꺼내든 쪼잔해 보인다
- **TripMate 라면**: 역할 화면 교통비 칸에 **"모두 나누면 9,600원 / 운전한 사람은 빼고 12,800원"**이 출발 전에 나란히 뜬다. 카카오 길찾기 거리·통행료와 그날 오피넷 기름값으로 셈한 값이라 "대충 10만 원이면 되지"가 안 나온다
- **아직 못 하는 것**: 수고비 금액은 그룹이 정한다(방 규칙 카드에서 할 일)

### 카드 2. "준비는 나 혼자, 돌아온 말은 피곤했다"
- **사연**: 숙소·일정을 단톡에 올려도 "잘 모르겠다"만 왔다. 계획과 길찾기를 한 명이 다 했다(네이트판, 조회 약 18.8만). 7명 가족 여행에서도 한 명이 다 맡고 나머지는 식당 불평(루리웹, 2024-12)
- **왜 싸웠나**: 의견 내는 비용이 크다. 단톡에서 "나 이거 싫어"를 말하기 어렵고, 말 안 하면 한 사람이 다 정한다
- **TripMate 라면**: 친구들은 링크 누르고 **다섯 번 탭**(차 있어? 계획형? 이건 빼 줘)으로 끝난다. 마지막 사람이 끝내면 **역할이 저절로** 정해지고 근거("계획형 +3")가 붙는다. 방장이 정한 게 아니라 설문이 정한 것이라 불평이 방장에게 안 간다
- **아직 못 하는 것**: 설문 안 한 사람에게 자동 카톡 알림(카카오 메시지 API 필요). 지금은 "한 번 더 알리기" 글을 공유 창으로 보낸다

### 카드 3. "69.9만 원 보고 갔다가 88.9만 원"
- **사연**: 7명이 가평 펜션을 기준 2인가만 보고 예약했다. 인원 추가비와 그릴비가 붙어 현금으로 88.9만 원을 냈다(헤럴드경제, 2025-08-31)
- **왜 싸웠나**: 가격을 사이트에서 한 사람만 봤고, 1인 몫은 아무도 미리 안 셌다
- **TripMate 라면**: 숙소 링크를 붙이면 **1박 가격을 읽어 와 "2박 8명이면 1인 약 6만 원"**까지 카드에 바로 보인다. 링크를 연 사람만 아는 숫자가 모두의 화면에 뜬다
- **아직 못 하는 것**: 기준 인원·추가요금은 아직 안 읽는다(다음에 지을 것 2번)

### 카드 4. "전날 빠지고 예약금 돌려 달래요"
- **사연**: 6명이 5만 원씩 내 방을 잡았는데 한 명이 전날 빠지고 환불을 요구했다. 댓글 쟁점은 "규칙을 미리 정했나"였다(루리웹, 2026-11-14)
- **왜 싸웠나**: 예외 규칙이 없었다. 돈 문제는 일이 터진 뒤에 정하면 누구 편을 들어도 남는다
- **TripMate 라면**: 지금은 답이 없다. **방 규칙 카드**(전날 불참 예약금, 운전자 기름값, 술값)를 방장이 처음에 고르고 모두가 보게 하는 것을 다음 기능 1순위로 잡았다
- **발표에서 말할 것**: 못 하는 것을 숨기지 않고 "조사에서 나와서 다음에 짓는다"로 보여 준다

### 카드 5. "카톡 1/N 정산 요청한 사람이 제일 많이 낸다"
- **사연**: 정산을 요청하는 총무만 자투리를 떠안는다는 글에 공감 댓글이 몰렸다(인스티즈, 2026-07)
- **왜 싸웠나**: 총무를 맡은 사람이 손해를 보는 구조라 아무도 총무를 안 하려 한다
- **TripMate 라면**: 총무를 **계획형 +3 같은 근거로 정하니** "왜 또 나야"가 줄고, 교통비·숙소 1인 몫이 미리 나와 총무가 계산할 게 적다. 실제 송금은 토스·카카오페이에 맡긴다(맞붙지 않고 잇는다)

### 30초 발표 멘트
"커뮤니티 글 31개를 읽었습니다. 가장 많이 싸운 건 '운전한 사람도 기름값 내냐'였고, 그다음이 '준비를 한 명이 다 한다'였습니다. 둘 다 출발 전에 안 정해서 생깁니다. TripMate 는 친구들이 다섯 번 누르면 역할이 근거와 함께 정해지고, 교통비는 '모두 나누면 / 운전자 빼면' 두 숫자를 출발 전에 보여 줍니다. 빠지는 사람 돈 문제는 아직 못 풀어서, 다음 기능으로 잡아 두었습니다."
