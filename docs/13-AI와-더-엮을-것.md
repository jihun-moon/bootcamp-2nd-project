# 13. AI 와 더 엮을 것(사람들이 더 쓰고 퍼뜨리게)

2026-11-20 조사. 웹 기사·공식 문서·앱스토어, 스레드 글을 읽었다. 숫자 중 원문을 못 연 것은 "확인 못 함"으로 둔다.

## 1. AI: 어디까지 넣나

| 서비스 | 하는 일 | 반응 |
|---|---|---|
| NOL | 'AI 노리'(2025-12), 항공 사면 일정판 자동 | 누적 수치는 원문 확인 못 함 |
| 카카오 카나나 | 단톡 요약(2025-09), 카나나 인 카카오톡(2026-03) | 맥락 없이 끼어들기, 상관없는 추천 지적 |
| 마이리얼트립 | AI 플래너(2023), AI 항공권 탐색(2026-02) | 이용자 수 확인 못 함 |
| Mindtrip | 그룹 채팅에서 AI 를 불러 모두의 취향 맞춤 | 날짜 오류 리뷰 |
| Expedia Romie | 단톡방에 들어가 요약 | 사생활 우려 |
| Layla | 대화로 일정 생성 | 휴관일 무시 같은 사실 오류, 일정 사라짐 불만 |

설문으로 본 신뢰: AI 사용자 만족은 높지만 휴가 계획에 AI 를 믿는 사람은 28%(카스퍼스키 2025-08 보도). AI 추천과 후기가 엇갈리면 68% 가 후기를 믿는다(클룩).

**정한 방향**: 일정표 전체를 AI 로 만들지 않는다(NOL·트리플과 정면, 틀리면 신뢰를 잃음, docs/10 과 같음). 대신 숫자(양·돈)는 서버 규칙으로 세고, AI 는 글을 뽑고 다듬는 일만 맡긴다. 후보:
- 카톡 '대화 내보내기' txt 를 붙여 넣으면 장보기·준비물 목록을 뽑는다(단톡방에 AI 를 들이지 않아도 됨)
- 역할 근거("차 있음 +4, 계획형 +3")를 한 문장으로 풀어 쓴다

비용(공식 가격표, 백만 토큰당): Haiku 5.5 입력 $0.10 / 출력 $0.50. 단톡 요약 한 번(입력 9천·출력 1.5천 토큰 가정) 약 2~5원, 방 1,000개 × 3번이면 한 달 1~1.5만 원. 한국어 토큰 수는 count_tokens 로 재야 한다.
막는 것: 공식 Java SDK 는 스택 표에 없는 새 의존성(팀 이슈 먼저), 키·선불 결제가 새로 필요, 다른 참여자 대화가 해외 API 로 나가니 국외 이전 고지·동의가 필요.

## 2. 이미 있는 키로 붙일 것

| API | 쓰임 | 키·한도 |
|---|---|---|
| 기상청 단기예보 | 출발 D-day + 여행 날 날씨, 비 오면 "바베큐 우천 대비" | 공공데이터 키(있음), 개발 10,000. 예보는 약 3일이라 먼 날은 "예보 전" |
| 카카오톡 공유 피드 카드 | 역할 결과를 그림 카드로 단톡방에 | JS 키(있음), 하루 3만 무료 |
| 카카오 로컬 | 숙소 근처 마트·편의점 거리 | 있음, 하루 10만 |

## 3. 퍼지게 하는 장치

- 유형 테스트: W컨셉 '추구미 테스트' 2주 18만 플레이(제목 기준). 우리 퀴즈("엑셀부터 켜는 총무형")가 같은 구조라 결과에 그림을 붙이면 된다
- 영수증 꼴: 커피 영수증 문구 게시물 하나가 490만 조회(한경 2026-07). 우리는 회비·교통비·역할·투표를 이미 가져서 '우리 여행 영수증'을 새 데이터 없이 만든다
- 초대 보상은 돈·약관 문제가 있고 커뮤니티가 추천 링크를 막는다. 우리는 방 링크 자체가 초대라 보상 없이 퍼진다

## 4. 스레드에서 본 시장 신호

트리플 종료(2026-11-03)를 아쉬워하며 대신 쓸 앱을 묻는 글(조회 약 1.2만)에 Somewhere, digo, 트래블맵모리, flyve, 울룰루 같은 개인·작은 팀 앱이 직접 댓글로 "트리플 일정 가져오기"를 들고 들어왔다. 일정·기록 앱 쪽은 이미 붐빈다. 우리는 일정표가 아니라 "여럿이 정하기"라서 이 줄에 끼지 않고, 이런 글에 "일정은 저기서, 운전·회비·숙소 정하기는 여기서"로 들어가는 것이 맞다.
