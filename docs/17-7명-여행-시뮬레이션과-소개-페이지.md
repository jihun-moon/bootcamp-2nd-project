# 17. 7명 여행 시뮬레이션, 그리고 소개 페이지를 끝까지 끌어올릴 계획

2026-11-20. 지훈이 "7명이 실제로 이 앱으로 정하고 여행까지 다녀오는 걸 가상으로 돌려 보고, 모자란 걸 찾아 달라"고 했다.
이야기를 하나 정하고, 실제 API 로 처음부터 끝까지 돌렸다(`SevenFriendsStoryTest`). 화면은 실제 카카오 로그인 방에서 봤다.

## 1. 이야기

대학 동기 7명이 1월에 강릉 2박 3일을 간다.

| 사람 | 특징 |
|---|---|
| 하늘 | 방장, 계획형, 차 없음. 밤 11시에 휴대폰으로 방을 만든다 |
| 준호 | 차 있음(5인승), 운전하니 술은 안 마심. 제일 빨리 답한다 |
| 소연 | 차 있음, 긴 운전은 싫다 |
| 민재 | 답이 늦다. 사흘 뒤에야 설문을 한다 |
| 예진 | 해산물을 못 먹는다 |
| 태오 | 돈이 빠듯하다. "1인 15만 원 넘으면 나는 빠질래" |
| 다인 | 갈지 말지 애매하다가 전날 빠진다 |

## 2. 실제로 돌려 본 순서와 걸린 곳

| 단계 | 된 것 | 걸린 것 |
|---|---|---|
| 방 만들기 | 달력·지역을 누르면 30초, 이름도 저절로 | 방 이름·지역을 나중에 고칠 수 없다 |
| 초대 | 카톡 공유 창, 링크 한 번 누르면 들어온다 | 처음 들어온 사람은 카카오 동의 화면을 한 번 거친다(어쩔 수 없음) |
| 날짜 맞추기 | 되는 날을 누르면 바로 겹친 날 후보 셋 | **날짜를 안 누른 사람을 부르는 단추가 없다.** 설문만 "한 번 더 알리기"가 있다 |
| 설문 → 역할 | 다 끝나면 저절로 정해진다 | **버그(고침).** 하늘이 바로 설문을 하고 준호가 1분 만에 들어와 설문을 끝내자, 그때 방이 2명이라 "모두 끝남"으로 보고 둘에게만 역할이 갔다. 저녁에 온 다섯은 빈손이었다(7명 중 2명). 지금은 배정 없는 사람이 생기면 다시 짠다. 누가 손으로 옮긴 카드는 지우지 않는다 |
| 방 규칙 | 운전자 기름값·불참 예약금·술값을 출발 전에 | 방장 혼자 정한다. 7명이면 "방장 마음대로?"가 나온다 |
| 숙소 | 링크 붙이면 사진·최저가·1인 얼마 | 태오의 "15만 원 넘으면 빠짐"을 넣을 칸이 없다. 예산 넘는 숙소를 표시하지 못한다 |
| 교통비 | 운전자 빼고 나누기, 카카오 길찾기 | **차 한 대(5인승)에 7명이 못 탄다는 경고가 없다.** 좌석 수를 묻지 않는다 |
| 장보기 | 사람 수·박 수로 양 계산, "내가 살게" | 술 마시는 사람 수를 방장이 손으로 줄여야 한다(설문에 안 물음). 예진이 못 먹는 해산물을 거를 수 없다. 품목은 정해진 11개뿐이라 "오리고기", "과자"를 더할 수 없다 |
| 전날 다인 불참 | 규칙 카드에 "예약금 안 돌려줌"은 보인다 | **방에서 나가거나 빼는 길이 없다.** 그래서 숙소·장보기·교통비 1인 금액이 모두 7로 나눈 채 틀린다 |
| 여행 중 | 없음 | 오늘 할 일, 체크인 시각, 운전 교대 같은 "그날 화면"이 없다 |
| 다녀와서 | 영수증 그림, 2탄 방(이번에 넣음) | **누가 누구에게 얼마를 보내야 하는지가 없다.** 숙소를 먼저 낸 사람, 실제 기름값을 넣으면 "준호에게 32,000원" 같은 줄이 나와야 한다(송금은 못 해도 표는 된다) |

## 4. 화면 폭마다 글이 잘리는 곳(이번에 같이 찾음)

크롬을 화면 없이 띄워 320·390·768·1440px 에서 "글이 자기 칸이나 감싼 칸 밖으로 나가 잘리는지"를 쟀다.

- 첫 화면 휴대폰: 대화가 위에서부터 쌓이고 아직 안 뜬 말도 자리를 차지해서, 768px 이상에서 마지막 말이 화면 아래로 잘렸다. 메신저처럼 새 말을 맨 아래로 바꿨다. 네 폭 모두 다 보인다.
- 영수증 그림: 긴 방 이름 줄이 옆으로 눌려 찍혔다. 낱말 단위로 줄을 나눈다.
- 체험 방, 로그인, 방 만들기, 방 안 6개 화면(25자 방 이름으로): 잘림 없음.

## 5. 재미: 홍보팀이 보면

- 역할 테스트 결과에 실제 사진, 한마디("집게는 내 거야"), 찰떡 짝꿍을 붙였다. "결과 카드 저장하기"는 1080x1920 스토리 그림이고, 바닥에 주소가 들어간다(그림이 곧 광고).
- 다음에 넣을 것:
  - **방 안 역할 보드 카드에도 같은 사진.** "도윤 = 엑셀부터 켜는 총무형"이 보드에 뜨면 단톡방 캡처가 늘어난다(역할 담당과 맞춰서).
  - **영수증 아래 "이번 여행 상"**: 최장 운전, 최다 투표, 장보기 영수증왕. 데이터는 이미 있다.
  - **2탄 방에 "지난번 운전 준호, 이번엔 쉬어요"** 한 줄. 역할 기록이 쌓일수록 공정해지는 재미.

## 6. 소개 페이지를 "끝판왕"으로: 계획

지훈 말대로 화면을 다 다듬은 뒤에 실제 화면을 찍어 쓴다. 순서를 거꾸로 하면 찍은 화면이 금방 낡는다. 첫 화면 휴대폰이 그랬다(장보기 칸 빠짐).

스레드에서 반복해서 본 것:

- 멈춘 캡처보다 10초 원테이크 영상이 퍼진다.
- 실제 녹화 대신 코드로 그린 제품 화면 + 커서 움직임(Stageshow, onetake)이 늘었다. 글자가 안 깨지고 고치기 쉽다.
- "AI 랜딩이 다 비슷한 이유"는 진짜 화면·사진이 없어서다.

우리 쪽 계획:

1. **스크롤하면 바뀌는 실제 화면.** 휴대폰 틀이 화면에 붙어 있고(sticky), 왼쪽 글이 지나갈 때마다 안의 화면이 바뀐다.
   - 날짜 달력이 칠해짐
   - 역할 도장
   - 숙소 1인 얼마
   - 장보기 "내가 살게"
   - 영수증 출력
   - 2탄 방
2. **화면은 실제 앱을 찍는다.** 이번에 만든 녹화기(`build/promo/record.mjs`, 크롬을 화면 없이 띄워 CDP 로 찍음)로 체험 방을 1080 폭으로 찍는다. 앱을 고치면 다시 돌리기만 하면 최신이 된다.
3. **손가락 표시.** 누르는 곳에 동그라미가 퍼지는 표시를 얹어, 무엇을 눌렀는지 보이게 한다.
4. **PC 와 휴대폰을 다르게.**
   - PC: 왼쪽 글, 오른쪽 휴대폰 고정.
   - 휴대폰: 글 한 단락 → 그 화면 한 장 → 다음 단락. 휴대폰에서 고정 틀은 화면을 다 가린다.
5. **SNS 용 10초 영상.** 같은 장면으로 9:16 영상을 뽑는다(이번에 만든 24초 초안의 다음 판).

## 7. 소개 글이 마음을 잡나(냉정하게)

- 잡는 것: 첫 줄 "운전 누가 해? 이제 단톡방에서 안 싸워요", 결과 세 줄, 공감 숫자(76·74·82%), 영수증 칸.
- 아직 약한 것:
  - **실제 사람이 쓴 흔적이 0이다.** 후기, 실제 방 수, 실제 영수증 그림이 없다. 배포 뒤 첫 10개 방의 영수증을 (허락받아) 첫 화면에 올리는 것이 어떤 문구보다 세다.
  - **"다른 데는 없는 것"이 스크롤 중간에 흩어져 있다.** 첫 화면 바로 아래 세 줄로 모아야 한다.
    - 왜 이 역할인지 근거
    - 운전자 빼고 나누기
    - 영수증 한 장
  - **소개 페이지 화면이 아직 실제 앱 캡처가 아니다.** 6절 계획으로 바꾼다.

## 8. 커뮤니티 불편과 대조(2026-11-20)

네이트판·에펨·디시·루리웹·82쿡·인스티즈·아하·블라인드(본문 막힘, 검색 요약만)에서 단체 여행 불편 22개를 모아 지금 기능과 맞췄다.

- **풀림(6):** 운전자 기름값, 차 여러 대 렌트비, 차 가진 사람에게 다 떠넘김, 뒷정리 혼자, 날짜 못 맞춤, 지각한 사람 없이 역할만 남음 → 역할 근거·운전자 빼고 나누기·날짜 맞추기
- **일부(9):** 운전 수고비, 술 안 마셨는데 1/n, 불참 예약금, 공동경비 부풀림 의심, 커플 동반 균등 분할, 정산 카톡 보내도 돈이 안 옴, 투표에 아무도 답 안 함, 인원 넘겨 펜션에서 쫓겨날 뻔함, 계획 혼자 다 짬
- **안 됨(7):** 가족 단위 나누기, 미리 걷는 돈 안 넣음, 침대 자리 다툼, 코골이 방 나누기, 지각·모일 시간, 사진 모으기, 공용 준비물 겹침

코드를 같이 보다가 찾은 것: **방 규칙 중 "술값 마신 사람만"과 "전날 빠지면 예약금"은 저장·표시만 되고 돈 계산에는 안 들어간다.** 정산·장보기는 기름값만 규칙대로 나누고 나머지는 모두 똑같이 나눈다. 규칙을 켜도 결과가 그대로라 오해를 산다.
