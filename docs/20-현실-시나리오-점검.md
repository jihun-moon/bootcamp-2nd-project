# 20. 현실 시나리오 점검 (2026-11-21)

지훈이 물었다. "각자 다른 지역에 살고 차 2대로 가는데, 차마다 가까운 곳에서 모여 가는 경우까지 다 생각했나. 손일은 적고 복잡하지 않나."
8명 예시 방을 처음부터 끝까지 돌리며(소개 화면을 찍은 `build/promo/tour.mjs`, 차 두 대 장면 `seed-cars.mjs`) 실제로 일어날 일을 하나씩 대 봤다.

## 이미 되던 것(다시 확인)

- 둘이 당일치기, 15명 4박, 차 없음, 아무도 술 안 마심(`FlexibilityTest`)
- 늦게 온 사람도 역할, 손으로 옮긴 카드는 그대로(`SevenFriendsStoryTest`)
- 방 나가기·빼기: 먼저 낸 돈은 정산에 남는다. 방장이 나가면 다음 사람이 방장(`LeaveTripTest`)
- 같은 이름 손님은 "민재(2)", 카톡 안 브라우저처럼 로그인이 끊긴 곳은 손님 기억하기와 정산 받는 링크
- 회비가 남으면 총무가 돌려주고 모자라면 더 보낸다. 총무가 나가도 낸 돈은 남는다(`DuesTest`)
- 두 사람이 동시에 누름: 역할 카드 409, 2탄 방 하나, 정산 링크 409 뒤 다시
- 방 지우기는 모든 기능 표를 지우고 다른 사람 화면은 첫 화면으로(`DeleteTripTest`)

## 손일 세기(참여자 한 사람 기준)

| 할 일 | 누르는 수 |
|---|---|
| 초대 링크 → 이름 → 들어오기 | 2 |
| 되는 날 | 날짜 수만큼(보통 3~5) |
| 설문 | 5 |
| 숙소 표 | 1 |
| 장보기 "내가 살게" | 맡을 때만 1 |
| 차 | 0(다른 차나 따로 갈 때만 1) |
| 회비 "냈어요" | 1 |
| 정산 "보냈어요" | 1 |

방장은 여기에 날짜 정하기 1, 규칙 3, 모이는 곳, 회비 금액이 더해진다. 차마다 태우는 곳은 그 차 운전자가 적어서 방장 혼자 다 챙기지 않는다.

## 아직 남은 것

- 보낼 줄 짝짓기가 차를 넘나든다. 재현 차에 탄 도윤이 민지에게 보낼 수 있다(사람마다 보낼 합은 맞다). 보내는 횟수를 줄이는 짝짓기라서다. 차마다 먼저 짝지으려면 `transfers` 에 무리 순서를 더한다
- 역할 화면의 미리 보는 교통비 어림값은 아직 두 차를 합쳐 나눈다(실제 정산은 차마다)
- 차 정원(5인승 등)을 넘겨도 알리지 않는다
- 회비 금액을 낸 뒤 바꾸면 이미 낸 사람은 옛 금액으로 남는다(차액은 정산이 맞춘다)
- 가족 단위 나누기, 코골이·침대 방 나누기, 사진 모으기, 일정표
- 카톡 안 브라우저·휴대폰 공유 창은 실제 기기로 한 번 눌러 봐야 한다
