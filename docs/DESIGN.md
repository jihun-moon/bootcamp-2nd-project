# TripMate 디자인 시스템

화면을 새로 만들거나 고칠 때 이 문서 하나를 본다. 값은 모두 `static/css/style.css` 맨 위 변수에 있고, 여기 없는 값을 새로 만들지 않는다.
까닭과 조사는 [08 화면 개편](08-화면-개편.md), [09 운영자 계정·글꼴](09-더-쓸-데이터와-운영자-계정.md)에 있다.

## 1. 원칙

1. **휴대폰(카톡 안 브라우저)이 먼저.** 넓은 화면은 `@media (min-width: 720px)` 로 넓힌다
2. **한 화면에 주 단추 하나.** 같은 곳으로 가는 단추는 한 화면에 한 번만
3. **사용자 말만.** 화면에 키 이름·파일·클래스·영어 오류를 쓰지 않는다. 까닭은 서버 로그에
4. **기본값처럼 보이지 않게.** 아래 6절 금지 목록에 둘 이상 걸리면 다시 만든다

## 2. 색

| 변수 | 쓰는 곳 | 쓰지 않는 곳 |
|---|---|---|
| `--accent` 청록 | 주 단추, 고른 탭, 입력칸 초점 | 링크, 칩, 제목, 장식 |
| `--warn` 주황 | 사람이 봐야 할 것(의견 갈림, 빠진 조건, 안내 칸) | 오류 |
| `--error` 빨강 | 실패·오류 글자 | 강조 |
| `--kakao` | 카카오 로그인 단추만(카카오 디자인 가이드) | 그 밖 전부 |
| `--ink` / `--muted` | 본문 / 보조 글 | |
| `--bg` / `--surface` / `--surface-2` / `--line` / `--line-strong` | 바탕 / 판 / 칩·옅은 바탕 / 선 / 손 올린 판의 선 | |

강조색은 화면의 5~10% 를 넘지 않는다. 다크 모드는 같은 변수 이름에 값만 바꾼다.

## 3. 글자·간격·모서리

| 무엇 | 값 |
|---|---|
| 글꼴 | Pretendard(가변), 못 받으면 시스템 글꼴 |
| 크기 | `--fs-xs 12` · `--fs-sm 14` · `--fs-md 16`(본문) · `--fs-lg 20` · `--fs-xl 24` · `--fs-2xl 32` |
| 굵기 | 제목 600(첫 화면 h1 만 700), 본문 400 |
| 줄 | 본문 1.5, 제목 1.3. 본문 한 줄 68자, 제목은 `text-wrap: balance` |
| 숫자 | `tabular-nums` |
| 간격 | 4·8·12·16·24·32·48 만 |
| 모서리 | 판 12(`--radius`), 누르는 것 6(`--radius-sm`). 카카오 단추 12(가이드). 휴대폰 틀만 예외 |
| 누름 크기 | 44px 이상(`--tap`) |

## 4. 부품

| 부품 | 클래스 | 언제 |
|---|---|---|
| 주 단추 | `.btn.primary` | 화면의 다음 할 일 하나 |
| 보조 단추 | `.btn` | 그 밖의 동작 |
| 글자 단추 | `.link` | 줄 안 작은 동작("+ 새 방") |
| 큰 단추 | `.btn.big`, 꽉 차게 `.block` | 첫 화면·폼 마지막 |
| 고르기 | `.choice`(고른 것 `.on`) | 설문 한 장 한 질문 |
| 칩 | `.chip`(있음 `.on`, 봐야 함 `.warn`) | 숙소 조건, 근거 |
| 판 | `.box` | 한 묶음. 판 안을 또 판으로 나누지 않고 `.rows` 줄로 |
| 바닥 시트 | `<dialog class="sheet">` | 휴대폰에서 고르기·편집(엄지 닿는 아래) |
| 토스트 | `showToast()` | "복사했어요"처럼 결과만 |
| 안내 칸 | `showNotice()` | 막힘·오류처럼 읽고 할 일이 있을 때 |
| 휴대폰 목업 | `.phone`, `.mini-phone` | 첫 화면 소개만 |

## 5. 움직임

| 변수 | 값 | 쓰는 곳 |
|---|---|---|
| `--ease` | `cubic-bezier(0.2, 0, 0, 1)` | 모든 움직임 하나 |
| `--dur-fast` | 120ms | 누름 `scale(0.97)`, hover 바탕 |
| `--dur` | 200ms | 카드 2px 들림, + 회전 |
| `--dur-slow` | 400ms | 장면 바뀜 |

- `transform`·`opacity` 만 움직인다
- hover 는 `@media (hover: hover)` 안에만(휴대폰은 hover 가 남는다)
- 내용은 기본으로 보이고, JS 가 있을 때만 나타남 효과를 붙인다
- `prefers-reduced-motion: reduce` 면 모두 끈다
- 하루에 수십 번 누르는 것(역할 옮기기, 투표)은 움직임을 길게 하지 않는다

## 6. 금지(기본값처럼 보이는 꼴)

이모지 아이콘 · 같은 크기 아이콘 카드 줄 · 알약 모양 · 모든 판에 그림자 · 파스텔 상자 · 카드 안 카드 · 판 옆 색 띠 · 제목 위 작은 글자 · 크림·베이지 바탕 · 유리·흐림 효과 · 보라 그라데이션·네온 · 출처 없는 숫자(예시면 "예시"라고 단다) · 글 속 이모지 · 엠대시(—)

## 7. 글(UX 라이팅)

- 해요체. "~합니다" 섞지 않는다
- 단추에는 누르면 일어날 일: "방 만들고 초대 링크 받기", "카톡용 글 복사"
- 오류는 까닭 + 할 일: "링크가 https:// 로 시작하는지 확인해 주세요"
- 빈 화면은 까닭 + 단추 하나: "아직 숙소가 없어요. 아래에 링크를 붙여 넣어 주세요"
- 민감한 것은 누가 보는지 먼저 말한다: "답은 본인과 방장만 봐요"
